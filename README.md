# 🍔 Menú de Hamburguesas

Proyecto realizado con HTML, CSS y JavaScript puro.

## Funcionalidades

- Agregar hamburguesas.
- Editar hamburguesas.
- Eliminar hamburguesas.
- Mostrar la lista de hamburguesas.
- Guardar los datos en LocalStorage.
- Mantener la información al recargar la página.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (ES6)
- LocalStorage

## Lo que aprendí

Durante este proyecto practiqué:

- Manipulación del DOM.
- Eventos (`addEventListener`).
- Arrays y objetos.
- `forEach`.
- `dataset`.
- `createElement`.
- CRUD (Crear, Leer, Actualizar y Eliminar).
- Persistencia de datos con LocalStorage.
